🚀 QUICK START (5 MINUTES)

  1. Install XAMPP (https://www.apachefriends.org/)
  2. Start Apache + MySQL in XAMPP Control Panel
  3. Copy files to: C:\xampp\htdocs\neema\
  4. Open browser: http://localhost/neema/
  5. Login with default credentials (see below)

❓ TROUBLESHOOTING

  Problem: White screen or errors
  Solution: Make sure Apache and MySQL are running in XAMPP

  Problem: Page not found
  Solution: Check files are in C:\xampp\htdocs\neema\

  Problem: Can't login
  Solution: Visit homepage first (auto-creates database)

  Problem: CSS not loading
  Solution: Hard refresh with Ctrl+F5

  📖 More help: See SETUP_GUIDE.md → Troubleshooting section
